# 🛫 Runway

> **Predictive Cash Flow & Autonomous Banking Engine**

Runway is an autonomous neobanking platform designed around financial correctness, predictive analytics, and event-driven architecture:

- **Core Engine:** Java 17 / Spring Boot 3 with an immutable double-entry ledger (PostgreSQL 16) and transactional consistency.
- **Event Bus & Gateway:** RabbitMQ event-driven transaction pipeline with Spring Cloud Gateway reverse proxy.
- **AI Intelligence:** FastAPI & local Ollama (Llama 3.1 8B) for stochastic cash flow runway forecasting and financial copilot tools.
- **Modern Web Dashboard:** Next.js 14 App Router, Tailwind CSS, and dark-mode analytics UI.
